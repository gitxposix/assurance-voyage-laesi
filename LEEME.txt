ARCHIVOS
admin/index.html: nueva consola (sustituye Decap).
admin/console-source.js y console.js: autenticación, formulario y activación.
assets/auth-redirect.js: envía los enlaces de invitación/recuperación a admin.
assets/babillard.js: lee el contenido publicado desde la función.
index.html y autres-assurances.html: páginas actuales con redirección de activación.
netlify/functions/babillard.mjs: lectura pública y publicación autenticada.
netlify/lib/babillard-core.mjs: valida contenido y permisos.
netlify/lib/initial.json: contenido inicial; no reemplaza publicaciones posteriores.
package.json, package-lock.json y netlify.toml: dependencias y despliegue.
Los demás archivos e imágenes del repositorio se mantienen. admin/config.yml antiguo no se utiliza con esta consola.

USO
Consola: https://fluffy-kataifi-dc826d.netlify.app/admin/
Usuario autorizado: eduardosoto30@hotmail.com
Título y mensaje independientes en FR y ES. Una imagen compartida.
La consola reduce imágenes JPG/PNG/WebP de hasta 5 MiB. El servidor comprueba y reduce a máximo 1200 × 800 px y 512000 bytes.
Publicar guarda ambos idiomas y la imagen juntos en Netlify Blobs. Recargar la web para ver el cambio. No crea commits GitHub ni requiere redeploy.
Las publicaciones persisten entre despliegues. Solo se permite escribir en el espacio del babillard; no existe API de modificación de otros archivos.
La consola permite descargar una copia JSON. Netlify conserva además la publicación inmediatamente anterior bajo la clave previous del almacén laesi-babillard.
Si el contenido dinámico no está disponible, la web puede usar el último archivo estático assets/babillard.json existente como respaldo.
